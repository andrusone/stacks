# stacks

Each service in the homelab runs on its own VM, declared in one stack map and deployed with one command. This repo replaces the stack part of the `network` repo; `network` stays as the reference for the standards it carries forward.

**Status:** spec accepted 2026-11-14. No code and no git repo yet.
